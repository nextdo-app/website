# Nextdo Website

Nextdo 产品官网（Astro 静态站点）。首页介绍 GTD 工作流、下一步行动推荐和本地优先理念。

## 开发

```bash
npm install
npm run dev
npm run build
```

Cloudflare Pages 部署：构建命令 `npm run build`，输出目录 `dist`。正式域名请在 Cloudflare Pages → Custom domains 中绑定。

> 首版为静态官网，Demo 页面不是真实产品截图；在线体验指向现有 Nextdo Web App。

应用仓库：https://github.com/nextdo-app/nextdo

在线体验：https://nextdo-cew.pages.dev
